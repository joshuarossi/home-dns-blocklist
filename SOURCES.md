# Sources and attribution

This feed consolidates the four subscriptions previously used on the home router.
Upstream content retains its original copyright and license terms. The MIT license
for the build scripts does not relicense upstream list data. The generated
`dist/source-notices.txt` preserves source comments and attribution from each build.

| Source | Original project | License information |
| --- | --- | --- |
| AdGuard DNS filter | https://github.com/AdguardTeam/AdGuardSDNSFilter | GPL-3.0, see the upstream repository |
| OISD Full | https://oisd.nl/ | GPL-3.0, see https://oisd.nl/faq |
| 1Hosts Lite | https://github.com/badmojr/1Hosts | MPL-2.0, see the upstream repository |
| Steven Black | https://github.com/StevenBlack/hosts | MIT for project contributions, with additional source-specific terms listed upstream |

Fetch URLs are recorded in `sources.json` and in every build manifest. No browsing
history, client addresses, router configuration, credentials, or network backups
are inputs to this published feed.
